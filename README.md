# Dineshkumar S — Portfolio

Free static portfolio for GitHub Pages.

## Before publishing
1. Put your PDF resume at `assets/DineshkumarSaravanan_Resume.pdf`.
2. In `index.html`, replace `YOUR_EMAIL@example.com` with your actual email.
3. Create a GitHub repository named `Dineshkumar152002.github.io`.
4. Upload all files from this folder to the repository and push to `main`.
5. GitHub → Settings → Pages → Source: **GitHub Actions**.
6. After the workflow completes, open:
   https://Dineshkumar152002.github.io

## Files
- `index.html` — portfolio content
- `style.css` — responsive dark theme
- `.github/workflows/deploy.yml` — free GitHub Actions deployment
- `assets/` — place resume PDF here
